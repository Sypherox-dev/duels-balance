## 📖 About

Everything that decides what happens in a **SkyWars Duels** round lives here, in the open: what you find in barrels and chests, how strong each kit is and more.
Nothing is hidden. The game servers read the files in this repository directly, so what you see here is **exactly** what is live in the game.

> [!NOTE]
> Changes are announced on our [Discord](https://sypherox.dev/discord) before or as they go live. If something feels different in game, check there first.

## 🔄 How it works

- Every duels server downloads the files **when it starts**. Because a server restarts after every round, each new round uses the latest version.
- If GitHub is unreachable or a file is broken, the server keeps the last working version, so a round is never blocked.
- GitHub caches raw files for a few minutes, so a change can take up to ~5 minutes to show up.

## 💬 Feedback

Found something unbalanced, or have an idea? Open a suggestion on our [Discord](https://sypherox.dev/discord) and tell us what you noticed. Please include the item or kit and how it felt in your rounds.
Values in this repository are changed by the SYPHEROX.DEV team, so pull requests are not needed.
